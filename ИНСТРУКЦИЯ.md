# 📦 VK Backup — Инструкция для чайников

> Скачивает **всю переписку ВКонтакте** на диск: сообщения, фото, голосовые, кружочки, документы, стикеры.
> Никаких знаний программирования не нужно — просто следуй шагам.

---

## Что тебе понадобится

- Компьютер с Windows
- Интернет
- 10 минут времени

---

## Шаг 1 — Установи Python

> Если Python уже стоит — переходи к Шагу 2.

1. Открой браузер и зайди на **[python.org/downloads](https://www.python.org/downloads/)**
2. Нажми большую жёлтую кнопку **"Download Python 3.x.x"**
3. Запусти скачанный файл
4. ⚠️ **ВАЖНО:** На первом экране установщика обязательно поставь галочку **"Add Python to PATH"** (внизу)
5. Нажми **"Install Now"** и дождись завершения

**Проверь что Python установился** — открой Пуск, найди **"Командная строка"** (или нажми Win+R, введи `cmd`, Enter) и напиши:
```
python --version
```
Должно написать что-то вроде `Python 3.12.0`. Если написало — всё ок.

---

## Шаг 2 — Получи токен ВКонтакте

> ⚠️ **Важно:** Старые ссылки авторизации через `oauth.vk.com` больше **не работают** — ВКонтакте заблокировал чтение сообщений для сторонних приложений.
> Скрипт использует современный **сессионный веб-токен** (тот же самый, через который работает веб-версия ВКонтакте).

### Способ 1 — Автоматически из Chrome (самый простой)
Если ты залогинен в ВКонтакте через **Google Chrome**, тебе вообще ничего не нужно копировать!
Скрипт сам при запуске найдет свежий сессионный ключ в хранилище Chrome на диске.

### Способ 2 — Через DevTools браузера (если другой браузер или Chrome не нашёл)
1. Открой [vk.com](https://vk.com) в любом браузере, где ты авторизован.
2. Нажми клавишу **F12** (или `Ctrl + Shift + I`), чтобы открыть панель разработчика.
3. Перейди на вкладку **"Сеть"** (или **"Network"**).
4. Обнови страницу (**F5**) или открой любой диалог в Мессенджере.
5. В строке фильтра напиши `method` или `im`.
6. Кликни **правой кнопкой мыши** по любому запросу (например, `messages.getHistory` или `al_im.php`) → выбери **"Копировать" (Copy)** → **"Копировать как cURL" (Copy as cURL)**.
7. Вставь скопированное в терминал, когда скрипт попросит токен. Скрипт сам моментально найдет нужный токен `vk1.a...` внутри cURL!

> 💡 **Автоподхват:** Скрипт умеет сам читать буфер обмена Windows. Если токен истёк — достаточно просто нажать "Copy as cURL", и программа сама подхватит его без вставки!

## Шаг 3 — Запусти скрипт

### Способ 1 — Через Проводник (самый простой)

1. Открой папку со скачанным скриптом (куда ты скачал или склонировал репозиторий `vk-backup`)
2. Кликни правой кнопкой мыши на **пустом месте** в папке
3. Выбери **"Открыть в терминале"** (или "Открыть окно PowerShell здесь")
4. Напиши и нажми Enter:
   ```bash
   python vk_backup.py
   ```

### Способ 2 — Через командную строку

1. Нажми **Win + R**, введи `cmd`, нажми Enter
2. Перейди в папку со скриптом и запусти:
   ```cmd
   cd C:\путь\к\папке\vk-backup
   python vk_backup.py
   ```

## Шаг 4 — Отвечай на вопросы скрипта

После запуска скрипт задаст несколько вопросов:

### Вопрос 1: Токен
```
Вставь токен:
```
→ Нажми **Ctrl+V** (вставить) и **Enter**. Можно вставить весь скопированный адрес целиком.

### Вопрос 2: Что скачать
```
Что скачать?
  1 — Все диалоги
  2 — Только личные переписки
  3 — Только беседы и группы
  4 — Один конкретный диалог
```
→ Напечатай цифру и нажми Enter. Для начала рекомендую **1** (всё).

### Вопрос 3: Подтверждение (если выбрал "Все")
```
Продолжить? [Y/n]:
```
→ Просто нажми **Enter** (или напечатай `y` и Enter).

## Шаг 5 — Жди

Скрипт начнёт скачивать. Ты увидишь что-то вроде:

```
👤 Иван Иванов  (peer_id=123456)
  ↓ 1 200/5 430 сообщений (22%)
  Скачиваем медиафайлы…
  Медиа: 5430/5430 ✓
  ✓ 5 430 сообщений → D:\vk_data\id111222\123456_Иван Иванов
```

**Сколько времени займёт:**
| Сообщений | Примерное время |
|-----------|----------------|
| до 5 000  | 5–10 минут |
| до 50 000 | 30–60 минут |
| более 100 000 | 1–3 часа |

> 💡 Можно прервать в любой момент (Ctrl+C) — при следующем запуске уже скачанные файлы пропустятся.

## Шаг 6 — Смотри результат

Когда скрипт закончит, он напишет:
```
✅ Готово!
Данные: D:\vk_data\id111222333\
Открой в браузере: D:\vk_data\id111222333\index.html
```

1. Открой **Проводник** → перейди на **диск D** → папка **vk_data**
2. Открой файл **index.html** (двойной клик — откроется в браузере)
3. Ты увидишь список всех диалогов — кликай на любой

## Частые вопросы

**❓ Написало "Токен не введён"**
→ Ты нажал Enter не вставив токен. Запусти снова и сначала вставь токен (Ctrl+V), потом Enter.

**❓ Написало "Ошибка авторизации: VK API #5"**
→ Токен недействителен или истёк. Повтори Шаг 2 и получи новый токен.

**❓ Написало "python не является внутренней командой"**
→ Python не установлен или установлен без галочки "Add to PATH". Переустанови Python (Шаг 1).

**❓ Кружочки не скачались, только ссылки**
→ ВКонтакте не разрешает скачивать все кружочки через API. Те что можно — скачались, остальные открываются по ссылке в браузере.

**❓ Можно ли запустить второй раз?**
→ Да. Скрипт умный — уже скачанные файлы пропускает. Запускай хоть каждый день чтобы докачать новые.

**❓ Скрипт завис посередине**
→ Нажми **Ctrl+C** чтобы остановить. Запусти снова — продолжит с того же места (медиа) или докачает новые сообщения.

**❓ Занимает много места на диске**
→ Это нормально. Если у тебя годы переписки с тысячами фото — может занять несколько гигабайт.

---

## Безопасность

- Токен хранится **только на твоём компьютере**, никуда не отправляется
- Скрипт обращается **только к серверам ВКонтакте** (api.vk.com)
- Токен с параметром `offline` не истекает сам по себе — но если хочешь отозвать доступ, зайди в ВК → Настройки → Безопасность → Активные сессии
