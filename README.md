# VK Backup & Archiver 📦

Утилита для полного скачивания и резервного копирования переписок ВКонтакте: сообщения, фото, кружочки, голосовые, видео, документы и стикеры.

Работает на **чистом Python 3.10+ без сторонних библиотек**.

---

## 🌟 Возможности

- 🛡️ **Актуально для 2024–2026 годов:** обходит блокировки старого API ВКонтакте, работая через современный протокол `web.api.vk.ru`.
- ⚡ **Автоматический поиск и автопродление токена:** скрипт автоматически находит свежий токен в локальном хранилище **Google Chrome, Яндекс.Браузера, Microsoft Edge, Opera, Brave** на диске. При истечении 15-минутного сессионного токена скрипт сам отправляет сигнал фонового обновления в открытый браузер и бесшовно подхватывает новый ключ без остановки загрузки!
- 💾 **Выбор места сохранения:** при старте можно указать любую папку на диске `D:`, `E:` или нажать Enter для папки по умолчанию.
- ⏱️ **Защита от флуда и бана IP:** встроен безопасный интервал обращений (0.35 с, строго до 3 запросов/сек по лимиту VK API) и адаптивный экспоненциальный backoff.
- 🔍 **Умное определение диалогов:**
  - Автоматически определяет имена собеседников, названия бесед и сообществ.
  - Поддерживает ссылки любого формата: `https://vk.com/im?sel=12345`, `im?sel=c5`, `im/convo/2000000001`, `vk.com/id123`, ники `@username` или числовые ID.
- ⭕ **Все типы вложений:**
  - 📷 **Фото** (в максимальном доступном разрешении)
  - ⭕ **Кружочки** (`video_message` в формате `.mp4`)
  - 🎙️ **Голосовые сообщения** (`.ogg` со встроенным плеером)
  - 🎬 **Видеозаписи**
  - 📎 **Документы и файлы**
  - 🎭 **Стикеры и граффити**
  - 📞 **Звонки, реакции и статусы**
- 📑 **3 формата экспорта:**
  1. `index.html` — современный веб-просмотрщик в тёмной теме в стиле ВКонтакте с аудиоплеером, медиа и фильтром по годам/месяцам/дням.
  2. `messages.txt` — чистый читаемый текстовый лог для мгновенного поиска через `Ctrl + F`, чтения в блокноте или анализа в LLM/нейросетях.
  3. `messages.json` — сырая база данных со всеми метаданными для безопасного хранения и докачки.
  4. Общий `index.html` в корне папки профиля со списком всех сохранённых диалогов и аватарками.

## 🚀 Быстрый старт

- Python 3.10 или новее.
- Дополнительных библиотек устанавливать **не требуется**.

### 2. Клонирование репозитория
```bash
git clone https://github.com/RABONCHIK/vk-backup.git
cd vk-backup
```

### 3. Запуск
```bash
python vk_backup.py
```

## 🔑 Как получить токен

ВКонтакте ограничивает доступ к чтению сообщений для сторонних приложений. Скрипт поддерживает самый надёжный способ — **сессионный веб-токен**:

### Способ 1: Автоматически из браузера (Chrome / Яндекс.Браузер / Edge / Opera)
Если вы авторизованы в ВКонтакте через Google Chrome, Яндекс.Браузер, Microsoft Edge, Opera или Brave — скрипт при запуске сам автоматически прочитает ключ из локального хранилища браузера на диске. Ничего копировать не нужно!

### Способ 2: Через DevTools (cURL)
1. Откройте [vk.com](https://vk.com) в любом браузере.
2. Нажмите `F12` (или `Ctrl + Shift + I`), перейдите на вкладку **Сеть (Network)**.
3. Обновите страницу (`F5`) или перейдите в «Мессенджер».
4. В фильтре напишите `method` или `im`.
5. Кликните правой кнопкой мыши по любому запросу → **Копировать (Copy)** → **Копировать как cURL (Copy as cURL)**.
6. Вставьте в терминал — скрипт сам извлечёт токен `vk1.a...` и ID пользователя.

```text
vk_backup_data/
└── id123456789/
    ├── index.html                   ← Главная страница со списком всех диалогов
    └── 987654321_Иван_Иванов/
        ├── index.html               ← Переписка в виде веб-страницы
        ├── messages.txt             ← Текстовый файл переписки
        ├── messages.json            ← Сырой JSON
        └── media/
            ├── photos/              ← Фотографии
            ├── circles/             ← Кружочки
            ├── voice/               ← Голосовые сообщения
            ├── videos/              ← Видео
            ├── stickers/            ← Стикеры
            └── docs/                ← Документы
```

## 🛡️ Безопасность и приватность

- Скрипт выполняется **исключительно локально** на вашем компьютере.
- Ваши токены, переписки и файлы отправляются **только на официальные серверы ВКонтакте и VK CDN**. Никаких внешних трекеров, серверов или телеметрии.
- Не передавайте третьим лицам сформированные архивы и файлы с токенами.
